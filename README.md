# LPBF Porosity Prediction Using Machine Learning

## Project Overview

This project applies Machine Learning to predict XCT-measured
porosity in AlSi10Mg components manufactured using Laser Powder
Bed Fusion (LPBF).

The objective is to investigate the relationship between selected
LPBF processing parameters and measured porosity.

A Random Forest Regressor is used to estimate porosity from:

- Laser Power (W)
- Scanning Speed (mm/s)
- Hatch Spacing (mm)

The trained model is integrated into an interactive Streamlit
application.

## Engineering Background

Laser Powder Bed Fusion is an additive manufacturing process
in which a laser selectively melts powder to build components
layer by layer.

Porosity is an important characteristic because pores can affect
the mechanical performance of manufactured components.

Processing parameters influence melt-pool behaviour and can
contribute to different types of porosity.

Machine Learning can help investigate relationships between
process parameters and measured material characteristics.

## Dataset

- Material: AlSi10Mg
- Manufacturing process: Laser Powder Bed Fusion
- Target: XCT-measured porosity
- Number of observations: 60

The dataset contains processing parameters and corresponding
porosity measurements.

The target unit and experimental conditions should be interpreted
according to the original dataset documentation.

## Machine Learning Workflow

1. Data cleaning and preparation
2. Exploratory Data Analysis
3. Feature engineering
4. Linear Regression
5. Random Forest Regression
6. Gradient Boosting Regression
7. Model evaluation using MAE, RMSE, and R²
8. Cross-validation
9. Hyperparameter tuning
10. Permutation feature importance
11. Prediction error analysis
12. Streamlit application development

## Model Evaluation

The original Random Forest model produced the following results
on the held-out test split:

| Metric | Value |
|---|---:|
| Mean Absolute Error | 1.5188 |
| Root Mean Squared Error | 2.5707 |
| R² Score | 0.4357 |

These results are preliminary and specific to the evaluation
split used during development.

The dataset is small, and the model showed substantial errors
for some high-porosity observations.

Performance on new experimental data may differ.

## Streamlit Application

The application allows users to enter:

- Laser Power
- Scanning Speed
- Hatch Spacing

It then displays the porosity estimate generated by the trained
Random Forest model.

## Limitations

- The dataset contains only 60 observations.
- The model does not predict all porosity levels equally well.
- Some high-porosity observations were substantially underestimated.
- The reported evaluation metrics are specific to the current test split.
- Performance on new experimental observations may differ.
- The model has not been validated for other alloys, machines, or manufacturing conditions.
- Predictions should not be interpreted as guaranteed manufacturing outcomes.
